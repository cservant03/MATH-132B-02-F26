    Definition 76. Binomial Probability Formula.

    If \(X\sim\operatorname{Bin}(n,p)\text{,}\) then
    🔗
    \begin{equation*} P(X=x)=\binom{n}{x}p^x(1-p)^{n-x},\qquad x=0,1,\ldots,n. \end{equation*}
    The combination counts the ways to place the successes among the trials:
    🔗
    \begin{equation*} \binom{n}{x}=\frac{n!}{x!(n-x)!}. \end{equation*}
    Here \(n!=n(n-1)\cdots 2\cdot 1\) and \(0!=1\text{.}\) Each particular arrangement has \(x\) successes and \(n-x\) failures, giving probability \(p^x(1-p)^{n-x}\text{.}\)
    🔗
    🔗

    Subsection Binomial Probabilities in R

    R uses size for the number of trials and prob for the probability of success on each trial. These functions are available in base R’s standard stats package.
    🔗
    For an integer cutoff \(k\text{,}\) use the following translations. Before calculating, list the counts the event includes.
    🔗
    In particular, \(P(X\lt k)=P(X\leq k-1)\) and \(P(X\geq k)=P(X\gt k-1)\) because counts are integers. Also,
    🔗
    \begin{gather*} P(X\gt k)=1-P(X\leq k),\\ P(X\geq k)=1-P(X\leq k-1). \end{gather*}
    The option lower.tail = FALSE returns the upper-tail probability directly and can be more accurate than subtracting from 1 when that probability is very small.
    🔗
