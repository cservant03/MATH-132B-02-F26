    Section Project 1: Categorical Data

    In this project, you will choose a data set that interests you and use categorical data methods to investigate questions about the data. You will summarize the data with tables and graphs and, later in the semester, use statistical inference to answer several research questions.
    🔗
    You are responsible for finding your own data. You may use one data set if it contains everything that you need, or you may use two related or unrelated data sets if one data set does not contain enough suitable categorical variables.
    🔗

    Subsection What You Need to Do First

    For now, concentrate on choosing your data and learning enough about the data to explain them to someone else. Do not begin performing statistical tests yet.
    🔗
    1. Find one or two data sets that contain suitable categorical variables.
      🔗
      🔗
    2. Identify the original source of each data set. Save the link to both the data and, when available, the page that explains how the data were collected.
      🔗
      🔗
    3. Determine what one row of the data represents. For example, one row might represent a person, patient, animal, plant, specimen, observation, county, or event.
      🔗
      🔗
    4. Identify the categorical variables that you might use in the project and determine what the categories mean.
      🔗
      🔗
    5. Check your data using the Data Selection Checklist below. You do not need to understand the statistical methods yet. The checklist is designed to help you find data that we will be able to analyze later.
      🔗
      🔗
    6. Begin writing your Data Set Summary. The completed Data Set Summary should be no more than one page.
      🔗
      🔗
    🔗

    Subsection Data Selection Checklist

    A good data set for this project should contain individual observations rather than only percentages or already-computed summary statistics. Whenever possible, each row should represent one observational unit and each column should represent a variable.
    🔗
    Look for a data set with several categorical variables. In particular, your data should allow you to answer yes to the following questions.
    🔗
    • Is there at least one categorical variable with two possible outcomes? Examples might include yes/no, positive/negative, present/absent, survived/did not survive, or another variable that can reasonably be separated into two categories.
      🔗
      🔗
    • Are there two meaningful groups that could be compared using the same two-category outcome? For example, you might be able to compare an outcome between two treatments, two populations, two locations, or two other groups.
      🔗
      🔗
    • Is there at least one categorical variable with three or more categories?
      🔗
      🔗
    • For a variable with three or more categories, can you find a reasonable outside source that describes what the distribution of those categories might be expected to look like? This could be a previously reported distribution, a scientific standard, a historical distribution, or another well-supported set of expected percentages.
      🔗
      🔗
    • Are there at least two categorical variables recorded for the same observations so that you can investigate whether those variables appear to be related?
      🔗
      🔗
    • Are there enough observations in the data that the categories are reasonably represented? A larger data set will generally be easier to use for this project. As a starting guideline, try to find data with at least 100 observations and avoid variables for which some categories contain only a few observations.
      🔗
      🔗
    The same variable may sometimes be useful for more than one part of the project. You do not need a different variable or a different data set for every analysis.
    🔗
    🔗

    Subsection Data Set Summary

    Your Data Set Summary should explain the data clearly enough that a reader who has never seen the data can understand what they represent. The completed Data Set Summary should be no more than one page.
    🔗
    Include the following information.
    🔗
    1. Topic and context. Explain what the data are about and why the topic is of interest.
      🔗
      🔗
    2. Source. Identify where you obtained the data and provide the original source whenever it is available.
      🔗
      🔗
    3. Observational units. Explain what one observation or one row in the data represents.
      🔗
      🔗
    4. Sample size. State the number of observations in the data that you plan to use.
      🔗
      🔗
    5. Population and sample. Explain, as well as you can from the available documentation, who or what was studied and the larger population that the data are intended to represent.
      🔗
      🔗
    6. Data collection. Briefly explain how the data were collected, if that information is available.
      🔗
      🔗
    7. Variables of interest. Identify the categorical variables that you expect to use. Explain what each variable measures and what its categories mean.
      🔗
      🔗
    8. Data preparation. Describe any filtering, removal of missing observations, recategorization, or other changes that you make to the original data.
      🔗
      🔗
    🔗

    Subsection Preliminary Research Questions

    Your exact research questions may change as we learn the statistical methods used in this project. For now, begin thinking about questions such as the following.
    🔗
    • What proportion of the observations has a particular characteristic?
      🔗
      🔗
    • Does the proportion with a particular characteristic appear to be different between two groups?
      🔗
      🔗
    • Does the distribution of a variable with several categories appear to agree with a known or expected distribution?
      🔗
      🔗
    • Does one categorical variable appear to be related to another categorical variable?
      🔗
      🔗
    At this stage, write these questions in ordinary language. You do not need to state hypotheses or identify statistical tests.
    🔗
    🔗

    Subsection Places to Look for Data

    The following sites are good places to begin looking for data. You are not required to use one of these sites, but any data set you choose should have a reliable source and enough documentation for you to understand what the variables represent.
    🔗
    • OpenIntro Data Sets contains many data sets used in introductory statistics courses, including biological, medical, and public-health examples. Many are available directly as CSV files.
      🔗
      🔗
    • TidyTuesday provides a large collection of real-world data sets on many different topics. Each week’s data usually includes information about the original source.
      🔗
      🔗
    • CDC Open Data contains public-health data from the Centers for Disease Control and Prevention. This is a particularly useful place to look for health-related categorical data.
      🔗
      🔗
    • UCI Machine Learning Repository contains data sets from many subject areas, including biology, medicine, and health. Many data sets include descriptions of each variable.
      🔗
      🔗
    • Data.gov provides data from federal, state, and local government sources. Searching by a topic such as health, disease, environment, animals, or population can help narrow the results.
      🔗
      🔗
    When a repository links to an original study or organization, you should also read the information from that original source. A data file by itself is usually not enough to understand how the data were collected or what the variables mean.
    🔗
    🔗

    Subsection Final Project Requirements

    By the end of the project, your report will contain the following major components.
    🔗
    1. Data Set Summary and Research Questions
      🔗
      🔗
    2. Tables and Graphical Analysis, including appropriate frequency tables, contingency tables, bar plots, and stacked bar plots.
      🔗
      🔗
    3. Statistical Analysis, including a one-proportion z test and/or confidence interval, a two-proportion z test, a multinomial distribution goodness-of-fit test, and either a test of homogeneity or a test of independence.
      🔗
      🔗
    4. Summary of Results that explains the statistical results in the context of your data rather than simply reporting computer output.
      🔗
      🔗
    5. Conclusion that answers the research questions, discusses what you learned from the data, and identifies important limitations. The conclusion should be no more than one page.
      🔗
      🔗
    🔗

    Subsection Grading Rubric

    The project is worth 50 points. Full credit requires both correct statistical work and clear communication of what the results mean in the context of the data.
    🔗

    Data Set Selection and Documentation: 5 points.

    • 2 points: The selected data set or data sets are appropriate for the required categorical analyses and contain sufficient observations and suitable variables.
      🔗
      🔗
    • 2 points: The source of each data set is clearly identified and documented. The original source is included when available.
      🔗
      🔗
    • 1 point: Any filtering, recategorization, removal of observations, or other modification of the original data is clearly documented.
      🔗
      🔗
    🔗

    Data Set Summary and Research Questions: 5 points.

    • 1 point: The topic and context of the data are clearly explained.
      🔗
      🔗
    • 1 point: The observational units, sample, population, and sample size are identified as completely as the available information allows.
      🔗
      🔗
    • 1 point: Variables of interest and their categories are clearly defined.
      🔗
      🔗
    • 2 points: Research questions are clearly written, meaningful in the context of the data, and appropriate for the statistical analyses used in the project.
      🔗
      🔗
    🔗

    Tables and Graphical Analysis: 10 points.

    • 2 points: Appropriate frequency and/or relative-frequency tables are included and are correct.
      🔗
      🔗
    • 2 points: Appropriate contingency tables are included and clearly organized.
      🔗
      🔗
    • 2 points: Appropriate bar plots are included and accurately represent the data.
      🔗
      🔗
    • 2 points: Appropriate stacked bar plots are included and help compare the categorical variables.
      🔗
      🔗
    • 2 points: Tables and graphs have meaningful titles, labels, category names, and other information needed for a reader to interpret them without referring to computer output.
      🔗
      🔗
    🔗

    Statistical Methods and Computations: 10 points.

    • 2 points: The one-proportion z test and/or confidence interval is selected and performed correctly.
      🔗
      🔗
    • 2 points: The two-proportion z test is selected and performed correctly.
      🔗
      🔗
    • 2 points: The multinomial distribution goodness-of-fit test is selected and performed correctly.
      🔗
      🔗
    • 2 points: The test of homogeneity or test of independence is selected and performed correctly.
      🔗
      🔗
    • 2 points: Conditions and assumptions are addressed appropriately, and calculations, notation, and statistical output are used correctly.
      🔗
      🔗
    🔗

    Results and Interpretation: 10 points.

    • 2 points: Results from the one-proportion analysis are accurately interpreted in context.
      🔗
      🔗
    • 2 points: Results from the two-proportion analysis are accurately interpreted in context.
      🔗
      🔗
    • 2 points: Results from the goodness-of-fit analysis are accurately interpreted in context.
      🔗
      🔗
    • 2 points: Results from the homogeneity or independence analysis are accurately interpreted in context.
      🔗
      🔗
    • 2 points: The report explains what the statistical results mean rather than simply listing statistics, p-values, or computer output.
      🔗
      🔗
    🔗

    Conclusion: 10 points.

    • 4 points: The conclusion clearly answers the major research questions using the results of the statistical analyses.
      🔗
      🔗
    • 2 points: The results are connected back to the original topic and interpreted in meaningful, nontechnical language.
      🔗
      🔗
    • 2 points: Important limitations of the data, study design, or conclusions are identified and discussed.
      🔗
      🔗
    • 2 points: The conclusion is clear, organized, concise, and written as a coherent summary rather than a list of statistical results.
      🔗
      🔗
