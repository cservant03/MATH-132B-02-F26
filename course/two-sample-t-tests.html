    Subsection Dependent Samples: Paired t-Test

    Requirements for Paired t-Test.

    1. The response is quantitative, and the target parameter is a population mean \(\mu\text{.}\) The population standard deviation \(\sigma\) is unknown.
      🔗
      🔗
    2. The data must be paired and the pairs should be independent from each other.
      🔗
      🔗
    3. The observations come from an appropriate random sample. When sampling without replacement, the sample should be no more than about 10% of the population.
      🔗
      🔗
    4. For a small sample, the differences should be roughly normal with no serious outliers. For a larger sample, inference is more tolerant of moderate nonnormality, but strong skewness and influential outliers still need attention.
      🔗
      🔗
    5. Use a histogram or normal Q-Q plot to inspect raw data. A Shapiro-Wilk result may supplement the plots; a large p-value does not establish normality.
      🔗
      🔗
    🔗
    🔗

    Paired t-Test.

    Choose an order and define one difference for each complete pair, \(d_i=x_i-y_i\text{.}\) Let \(\bar d\) and \(s_d\) are the sample mean and sample standard deviation of the differences. If the hypothesized mean difference is \(\mu_d\text{,}\) then
    🔗
    \begin{gather*} H_0:\mu=\mu_d,\qquad t=\dfrac{\bar d- \mu_d}{\dfrac{s_d}{\sqrt n}},\qquad df=n-1. \end{gather*}
    🔗
    Here \(n\) is the number of complete pairs. Usually \(\mu_d =0\text{.}\) The alternative is \(\mu <\mu_d\text{,}\) \(\mu >\mu_d\text{,}\) or \(\mu \ne\mu_d\text{.}\)
    🔗
    🔗
    # x and y must be in the same participant order.
d = x - y
hist(d)
qqnorm(d)
qqline(d)

# Two equivalent ways to perform a two-sided paired test:
t.test(x, y, paired = TRUE, mu = 0, alternative = "two.sided")
t.test(d, mu = 0, alternative = "two.sided")
    With summary statistics for the differences, calculate \(t\) from the formula and use pt(). With raw paired data, t.test(x, y, paired = TRUE) uses the differences x - y. Use "greater" or "less" when that matches the alternative. If a measurement is missing, omit the entire incomplete pair and count the remaining pairs; never remove missing values separately and then pair the shortened columns.
    🔗
    For each test example, define the parameter and subtraction order, state the hypotheses, identify where the claim belongs, check the requirements, find the test statistic, degrees of freedom, and p-value, make the decision, and conclude in context.
    🔗

    Subsection Independent Samples: Welch’s t-Test

    Requirements for Two-Sample t-Test.

    1. The response is quantitative. Observations are independent within each sample and between the groups, with appropriate random sampling or random assignment.
      🔗
      🔗
    2. For small samples, each population should be approximately normal without serious outliers. Examine each group separately. Larger samples allow more tolerance for moderate nonnormality.
      🔗
      🔗
    3. Welch’s procedure does not assume equal population variances.
      🔗
      🔗
    4. Label Groups 1 and 2 explicitly. The sign of the statistic and the direction of a one-sided test depend on that order.
      🔗
      🔗
    🔗
    🔗

    Welch’s Independent Two-Sample t-Test.

    \begin{equation*} t=\dfrac{(\bar x_1-\bar x_2)-\Delta_0}{\sqrt{\dfrac{s_1^2}{n_1}+\dfrac{s_2^2}{n_2}}} \end{equation*}
    🔗
    The degrees of freedom are
    🔗
    \begin{equation*} \rm{df}=\dfrac{\left(\dfrac{s_1^2}{n_1}+\dfrac{s_2^2}{n_2}\right)^2}{\dfrac{(s_1^2/n_1)^2}{n_1-1}+\dfrac{(s_2^2/n_2)^2}{n_2-1}} \end{equation*}
    🔗
    We will approximate df when doing calculations by hand with
    🔗
    \begin{equation*} \rm{df} = \min \left( n_1 - 1, n_2 - 1 \right) \end{equation*}
    🔗
    🔗
    For raw observations, use the vector order group1, group2. The option var.equal = FALSE selects Welchss method and is also Rss default.
    🔗
    t.test(group1, group2, mu = 0, alternative = "two.sided", var.equal = FALSE)
